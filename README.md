# 🌌 NexusCore OS v1.0

NexusCore adalah framework CMS Portofolio & Marketplace yang dirancang khusus untuk tech-enthusiast. Dengan sistem modul, Anda bisa mengaktifkan atau mematikan fitur Toko sesuai kebutuhan.

## 🚀 Fitur Unggulan
- **Modular System:** Aktifkan/Matikan fitur "Shop" melalui dashboard.
- **AI Chatbot Integration:** Chatbot bertenaga AI untuk menyapa pengunjung.
- **Smart Commerce:** Keranjang belanja, manajemen stok, dan Flash Sale timer.
- **Terminal UI:** Preloader bertema hacker dan desain Glassmorphism Dark Mode.
- **Telegram Notify:** Notifikasi pesanan instan dengan tombol balas cepat.

## 🛠️ Instalasi Cepat
1. **Upload:** Unggah semua file ke folder `htdocs` hosting Anda.
2. **Database:** Import `database.sql` ke phpMyAdmin.
3. **Config:** Edit `config.php` untuk mengatur Database dan `RECOVERY_EMAIL`.
4. **Login:** Akses `gate-access.php` (User: `admin` | Pass: `nexus2026`).

## ⚠️ Keamanan
Fitur ganti password dan pengaturan sistem dikunci ke email yang Anda daftarkan di `config.php`. Pastikan email tersebut valid untuk mencegah pengambilalihan akun.
